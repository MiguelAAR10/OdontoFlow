# Handoff — ERP-AGENTICO-01 · B1 ToolSpec registry + server allowlist + catalog

## Summary
- `app/agent_tools/registry.py`: single `ToolSpec` source for the 16 tools (args model, handler, effect, level L0-L4,
  permissions, needs_conversation, description). The Literal/sets/`ARGUMENT_MODELS` are derived from it. Dispatch goes
  through the registry, and the if/elif is gone.
- Server allowlist per `agent_key`, in code. `reception` = the 16 tools minus the L4 `confirm_*`. An agent principal
  outside the allowlist, or on any L4 tool, gets 403 `PERMISSION_DENIED` plus a `security_events` row `agent_tool_denied`.
- `conversation_id` is optional. `GET /agent-tools/catalog` returns the tools allowed to the caller.
- Gateway: stable `Idempotency-Key` per logical action (UUIDv4-shaped hash of conversation, turn inbound message, tool
  and canonical args). A mutation timeout returns `OUTCOME_UNKNOWN` and is routed to human recovery. langgraph 1.2.12,
  langchain 1.4.3.

## Merge danger / risks (debt for B4)
- An agent principal without a mapping falls back to `reception`. The lookup key is `Principal.display_name`, which is
  mutable and not unique. `agent_definitions` in B4 must replace this.
- `integration` principals are governed by permissions only, so one with the conversation-agent profile still sees
  all 16 tools.
- The key canonicalizer normalizes `datetime` objects only. ISO strings with different offsets hash differently.
